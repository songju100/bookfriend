# 공유 도서목록

- `books.js`는 웹사이트에 표시되는 기본 추천도서 목록입니다.
- 공유할 책은 `window.BOOKS` 배열에 한 항목씩 추가하고 변경 사항을 저장소에 커밋한 뒤 다시 배포합니다.
- 각 항목에는 `title`, `author`, `publisher`, `level`, `tags`, `month`, `source`, `url`, `summary`, `status`를 기록합니다. 실물책의 `callNumber`, 전자책 목록과 대조할 `isbn`은 확인된 경우에만 추가합니다.
- `summary`는 교보문고 또는 추천기관의 책 소개를 확인해 짧게 자기 말로 요약합니다. `url`은 검토한 원자료 링크를 지정합니다.
- 사이트에서 직접 등록한 책은 현재 브라우저에만 저장되며 `내가 등록한 책` 영역에서 확인할 수 있습니다. 공유 카탈로그는 관리자가 `books.js`를 수정해 배포합니다.
- `ebooks.js`는 제공된 2026 전자책 목록에서 상품종류가 `eBook`인 항목의 제목·저자·출판사·ISBN만 보유합니다. 가격·구매 수량 등은 제외하며, 이 목록 전체를 추천도서로 자동 등록하지 않습니다.
- 추천도서 카드에서 ISBN 또는 제목이 전자책 목록과 일치하면 `우리학교 전자책 대출·열람` 링크를 표시합니다. 링크는 학교 전자도서관으로 연결되며 실제 대출은 학교 계정 로그인 후 진행합니다.
- `holdings.json`은 실물 소장도서의 `callNumbers`를 사용합니다. 전자책에는 청구기호를 표시하지 않습니다.
- `holdings.json`은 DLS 소장목록에서 단행본의 제목·저자·출판사·출판년도·청구기호만 추린 검색 자료입니다. 공개 저장소에 포함되므로 등록번호, 대출상태, 반납예정일, 구입정보, 가격은 내보내지 않습니다. 청구기호 800번대는 문학 검색에 사용합니다. 새 목록을 받으면 같은 항목을 추려 다시 생성하고 배포합니다.


## 추천 통합 데이터

- `holdings.json`: 학교 실물 소장도서. 검색 카드에는 제목 아래 `청구기호`로 표시합니다. 등록번호·대출상태 등 이용자 정보는 포함하지 않습니다.
- `career.json`: 경기도교육청 진로도서목록 822종. 청구기호 기반 분류로 인문·사회·교육·자연·공학·의약·예체능 계열을 제공합니다.
- `curriculum.json`: 경기도교육청 고등학교 교과연계 도서목록 209종(중복 제거). 원본의 교과·계열 정보와 서지사항을 포함하며 가격은 제외했습니다.
- `reviews.json`: 사용자가 제공한 2026년 1~10월 DLS PDF에서 추출한 서평도서 90종(고등학생용; 2월 초등고학년 자료 제외). 제목·저자·출판사·연도·월별 주제·대상 학년만 포함하며, 서평 전문과 서평자/학교 정보는 포함하지 않습니다. 교보문고 책 소개는 결과 카드의 제목 검색 링크에서 확인합니다.
- Pages 배포 workflow는 위 JSON 파일들을 `_site/data/`에 복사합니다. 앱은 추천 검색 실행과 동시에 기본 추천을 표시하고 나머지 자료를 백그라운드에서 불러옵니다. 자료가 없으면 비슷한 주제 후보를 표시합니다.
- 데이터 레코드 공통 필드: `id`, `title`, `author`, `publisher`, `year`, `categories`, `sectors`, `themes`, `source`, `url`; 학교 소장 자료만 `callNumbers`를 가집니다. 요약이 없는 목록은 교보문고 제목 검색으로 원문을 확인할 수 있습니다.

- 직접 등록한 도서는 `bookbud-custom` 브라우저 localStorage에 저장됩니다. 저장은 현재 브라우저/기기에 한정되며, 화면의 내가 등록한 책 영역에서 다시 볼 수 있습니다.

- `nlcy.json`은 업로드된 국립어린이청소년도서관 사서추천도서목록에서 청소년/중·고등 대상 568종의 서지·주제 정보만 추렸습니다. 추천사서 이름과 소개글은 포함하지 않으며, 자료원 링크는 에듀넷 사서추천도서 페이지로 연결합니다.
- NLCY 도서와 학교 소장목록이 제목·저자 기준으로 유일하게 식별되면 한 카드로 합칩니다. 대표 출처는 국립어린이청소년도서관 도서목록으로 표시하고, 소장 청구기호는 함께 유지합니다.
- 소개글 기반 난이도 표시는 읽기수준의 공식 판정이 아닌 브라우저 내 규칙 추정입니다. 기존 난이도 값을 우선하며 소개글이 없는 도서는 대상 학년만 표시합니다.
