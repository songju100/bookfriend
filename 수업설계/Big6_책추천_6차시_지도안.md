# 책벗: Big6 Skills 기반 도서추천 수업 6차시 지도안

## 수업 개요

- 대상: 고등학교 도서부 학생 (2인 1조 또는 3인 1모둠)
- 차시: 6차시, 차시당 50분 기준
- 과제: 친구 한 명의 독서 요구를 파악하고, 근거에 맞는 책 한 권을 추천해 도서관 안팎에 큐레이션한다.
- 기본 기기: 학생 태블릿. PC실에서는 같은 웹사이트와 활동지를 사용한다. 휴대전화에서는 결과물 확인/게시 위주로 쓴다.
- 준비물: 책벗 사이트, 도서관 서가, 태블릿/PC, 포스트잇, 출력용 추천 카드, 선택적으로 Padlet.
- 운영 원칙: 실명·개별 대출 이력은 묻지 않고 별칭 사용. 추천받는 학생은 불편한 질문을 건너뛸 수 있다. 학교 게시 규정과 온라인 공유 범위를 지킨다.

## 학습 목표

1. 추천 대상의 요구를 구체적인 탐구 과제로 정의한다.
2. 목적에 적합한 정보원과 검색 전략, 평가 기준을 세운다.
3. 도서관과 온라인 자료원에서 책 정보를 찾고 출처를 확인한다.
4. 책·목차·미리보기·신뢰할 수 있는 소개를 바탕으로 필요한 정보를 추출한다.
5. 책의 특징과 독자의 요구를 연결해 추천 콘텐츠를 만든다.
6. 탐색 과정과 추천 결과를 평가하고 실제 독자 반응에 따라 개선한다.

## 차시별 지도안

### 1차시 — 과제 정의 (Task Definition)

**핵심 질문:** “누구에게, 어떤 상황에서, 어떤 책을 왜 추천할까?”

| 시간 | 교수·학습 활동 |
|---|---|
| 5분 | 도서부의 역할과 최종 과제 소개. 마음에 남았던 추천 경험을 짝과 나눈다. |
| 10분 | 사이트에서 별칭을 정하고, 사서교사가 시범 인터뷰를 보여준다. 독서 빈도나 대출 이력 대신 ‘요즘 궁금한 것·읽고 싶은 기분·읽을 수 있는 분량’을 묻는다. |
| 15분 | 짝 인터뷰: 관심 분야, 읽을 상황, 원하는 느낌, 선호 길이를 선택/기록한다. 답변하지 않을 권리도 안내한다. |
| 10분 | 개인 또는 짝별로 요구를 한 문장으로 바꾸고, 과제 질문을 만든다. |
| 10분 | 서로 질문을 바꿔 읽고 대상과 상황이 분명한지 확인한다. |

- **교사 지원:** 사생활을 파고드는 질문을 예시로 보여주고 안전한 대체 질문을 모델링한다. ‘책을 많이 읽는 학생’만을 기준으로 삼지 않도록 한다.
- **학생 산출물:** 별칭 독자 프로필, 추천 과제 질문.
- **형성 평가:** 대상·상황·필요가 한 문장 안에 드러나는가?
- **예시 문장:** “새 학기 적응이 어색한 친구가 부담 없이 읽으며 우정에 대해 생각할 책을 찾는다.”

### 2차시 — 정보탐색전략 수립 (Information Seeking Strategies)

**핵심 질문:** “어떤 자료원을 어떤 기준으로 살펴보면 좋을까?”

| 시간 | 교수·학습 활동 |
|---|---|
| 5분 | 1차시 질문과 독자 요구를 다시 확인한다. |
| 10분 | 자료원 지도를 살펴본다: 국립어린이청소년도서관(사서 추천), 책따세(고등학생 수준/분야/추천글), 독서로(학교 소장도서 검색), 학교 전자도서관(전자책), NCIC(교육과정·성취기준 확인). |
| 15분 | 주제어·동의어·교과 용어를 확장해 검색어 3개 이상을 만든다. 제목/저자/주제, 대상, 발행 시기, 목록 기준을 정한다. |
| 10분 | 후보 평가 우선순위를 정한다: 독자 흥미 적합성, 출처 신뢰성, 읽기 부담, 주제 적절성, 우리 학교에서 읽을 수 있는지. |
| 10분 | 자료원별로 확인할 정보와 접속 실패 때의 대체 방법을 탐색 계획표에 적는다. |

- **교사 지원:** NCIC는 교육과정 자료원이고 도서 추천 목록은 아니라는 점을 분명히 한다. 교과 연계는 성취기준과 책의 실제 내용을 대조해 판단하도록 한다.
- **학생 산출물:** 검색 전략 및 평가 우선순위표.
- **형성 평가:** 자료원마다 확인할 항목이 다르게 정리되었는가?
- **평가 기준 예시:** 신뢰성(공식 추천/전문가 글), 적합성(독자 요구와 주제 일치), 접근성(소장/전자책 확인), 최신성(목록 연도 기록).

### 3차시 — 소재 파악 및 접근 (Location and Access)

**핵심 질문:** “책과 정보를 어디에서 찾고, 필요한 정보에 어떻게 접근할까?”

| 시간 | 교수·학습 활동 |
|---|---|
| 5분 | 검색 전략과 역할(검색자·기록자)을 정한다. |
| 15분 | 국립어린이청소년도서관과 책따세에서 후보를 찾는다. 제목·저자·추천 대상/수준·추천 연도·소개글 링크를 기록한다. |
| 15분 | 독서로에서 구리여고 소장 여부를 직접 검색하고, 학교 전자도서관에서 전자책 제공 여부를 확인한다. 결과와 확인 날짜를 적는다. |
| 10분 | 도서관 서가에서 후보를 찾아 실제 책의 청구기호·대출 가능 여부를 확인한다. NCIC 성취기준을 참고할 경우 해당 과목·기준도 함께 기록한다. |
| 5분 | 후보 3권을 비교하고 불확실한 항목은 ‘확인 필요’로 표시한다. |

- **교사 지원:** 학교 링크를 통한 진입 경로와 사이트 검색 시연을 준비한다. 서비스 장애/로그인 문제 시 공개 추천목록, 서가, 교사 제공 목록으로 대체한다. 소장 여부를 추정해 기록하지 않도록 한다.
- **학생 산출물:** 후보 도서 3권의 서지·출처·소장 확인표.
- **형성 평가:** 제목·저자·출처 URL·확인 날짜·소장 상태가 분리 기록되었는가?

### 4차시 — 정보 이용 (Use of Information)

**핵심 질문:** “책에서 어떤 내용을 읽고, 추천 근거로 가져올까?”

| 시간 | 교수·학습 활동 |
|---|---|
| 5분 | 후보 도서 중 2권을 골라 확인할 질문을 정한다. |
| 20분 | 실물 책의 목차/일부를 읽거나 전자책 미리보기·공식 추천글·서점 소개를 읽는다. 독자 요구와 관련된 핵심 키워드, 분위기, 읽기 부담을 메모한다. |
| 10분 | 책 소개의 정보와 자신의 해석을 나누어 기록하고, 인용 대신 짧은 자기 말 요약을 작성한다. |
| 10분 | 난이도를 ‘가볍게 읽기/보통/깊이 읽기’ 중 임시 판단하고 페이지 수·어휘·배경지식·주제 복합성 등 근거를 덧붙인다. |
| 5분 | 가장 적합한 후보 1권과 추천 근거를 결정한다. |

- **교사 지원:** 한 문장 추천 근거 틀을 제공한다: “네가 ___에 관심 있다고 해서, 이 책의 ___ 부분이 ___하게 다가올 것 같아.”
- **학생 산출물:** 정보 추출 메모, 난이도 판단 근거, 추천 후보 1권.
- **형성 평가:** 요약/해석/근거의 출처가 구분되는가? 책 내용을 읽거나 확인한 흔적이 있는가?
- **저작권:** 교보문고 등 서점 소개글을 그대로 전재하지 않고 짧게 요약하며 원문 링크를 남긴다.

### 5차시 — 정보 종합 (Synthesis)

**핵심 질문:** “조사한 정보를 친구가 읽고 싶어지는 추천으로 어떻게 엮을까?”

| 시간 | 교수·학습 활동 |
|---|---|
| 5분 | 추천 카드/포스터 예시를 보고 필수 요소를 확인한다. |
| 20분 | 사이트에서 책을 선택하고 추천 대상·이유·짧은 소개·난이도·주제·출처를 구성한다. |
| 10분 | 태블릿에서 카드 미리보기 또는 출력물을 점검한다. 큰 글자, 짧은 문장, 대비, QR/출처 접근성을 살핀다. |
| 10분 | 다른 모둠이 ‘이 추천이 나를 위한 이유가 보이는가?’를 기준으로 동료 피드백을 준다. |
| 5분 | 피드백을 반영하고 게시용 최종본을 저장/인쇄한다. |

- **교사 지원:** 결말 스포일러, 낙인 표현(“책을 안 읽는 친구”), 개인정보, 확인되지 않은 소장 정보를 점검한다.
- **학생 산출물:** 도서 추천 카드/포스터, Padlet 게시문(선택).
- **형성 평가:** 대상 요구와 책의 특징을 구체적인 근거로 연결했는가?

### 6차시 — 정보 평가 (Evaluation) 및 현장 큐레이션

**핵심 질문:** “과정은 믿을 만했고, 추천은 실제 독자에게 닿았을까?”

| 시간 | 교수·학습 활동 |
|---|---|
| 5분 | 과정·결과 평가 기준을 확인하고 게시 장소·온라인 공유 범위를 정한다. |
| 10분 | 동료평가: 출처와 소장 확인, 추천 적합성, 소개의 정확성, 읽기 쉬운 디자인을 점검한다. |
| 15분 | 실제 도서관 안팎의 지정 게시 공간에 큐레이션을 설치한다. Padlet 공유는 교사가 정한 학급 공개 범위 안에서 한다. |
| 10분 | 독자가 남긴 익명 스티커/댓글/QR 응답을 확인하고 반응을 기록한다. |
| 10분 | 성찰: 다음에는 무엇을 바꿀지 개인/모둠별로 기록하고 추천 활동을 마무리한다. |

- **교사 지원:** 게시 허가, 저작권, QR 안전, 온라인 개인정보/댓글 관리 기준을 사전에 안내한다. 이용자 사진이나 실명은 동의 없이 기록하지 않는다.
- **학생 산출물:** 실제 큐레이션, 과정·결과 평가표, 독자 반응과 성찰 기록.
- **총괄 평가:** 정보탐색의 과정과 추천 결과를 모두 평가하며, 많이 찾기보다 근거와 대상 적합성을 중시한다.

## 과정·결과 루브릭 (4수준)

| 기준 | 4 매우 잘함 | 3 잘함 | 2 발전 중 | 1 시작 단계 |
|---|---|---|---|---|
| 과제 정의 | 독자·상황·필요가 구체적이고 존중하는 질문으로 표현됨 | 필요한 요소 대부분이 드러남 | 요구가 넓거나 일부 모호함 | 대상/필요가 드러나지 않음 |
| 탐색 전략·출처 | 자료원 선택 이유와 검색어가 적절하고 출처/확인 날짜가 정확함 | 적절한 자료원과 출처를 기록함 | 자료원 또는 출처 기록이 일부 빠짐 | 출처를 확인하기 어려움 |
| 정보 이용·근거 | 책 내용을 확인하고 사실·해석을 구분해 근거를 연결함 | 책 소개/목차 등 근거를 사용함 | 근거가 일반적이거나 요약에 치우침 | 책 내용을 확인한 흔적이 부족함 |
| 추천 결과물 | 대상 맞춤 이유, 정확한 정보, 읽기 쉬운 디자인, 출처가 모두 분명함 | 주요 정보와 추천 이유가 읽기 쉬움 | 추천 이유/출처/가독성 중 보완 필요 | 독자에게 적합한 이유를 알기 어려움 |
| 평가·성찰 | 실제 반응을 활용해 과정과 결과 개선점을 구체적으로 제안함 | 과정/결과를 돌아보고 개선점을 적음 | 성찰이 단편적임 | 평가/성찰 기록이 없음 |

## 연간 테마 운영 예시

| 월 | 테마 예시 | 연계 가능한 관심 |
|---|---|---|
| 1월 | 새해, 새 마음 | 성장, 습관, 마음 돌봄 |
| 2월 | 우정과 관계 | 친구, 가족, 다름, 소속감 |
| 3월 | 새 학기와 진로 | 배움, 진로, 학교생활 |
| 4월 | 책과 지구 | 독서, 생태, 기후 |
| 5월 | 돌봄과 감사 | 가족, 스승, 공동체 |
| 6월 | 환경과 평화 | 생태, 공존, 평화 |
| 7월 | 여름의 발견 | 여행, 모험, 과학 탐구 |
| 8월 | 광복과 우리 사회 | 역사, 민주주의, 다양성 |
| 9월 | 읽기와 배움 | 문해력, 새로운 배움 |
| 10월 | 한글과 문화 | 언어, 문화, 예술 |
| 11월 | 학생의 질문 | 과학, 미래, 청소년의 목소리 |
| 12월 | 인권과 나눔 | 인권, 연대, 한 해 성찰 |

테마는 학교 연간 교육계획과 실제 기념일 날짜에 맞춰 교사가 조정한다. 월별 테마는 특정 날짜에 대한 단정 대신 질문형 큐레이션으로 운영한다.

## 도서 선정·확인 체크리스트

- [ ] 국립어린이청소년도서관/책따세 등 원 자료원에서 제목·저자·선정 대상 또는 수준을 확인했다.
- [ ] 우리 학교 소장 여부와 전자책 제공 여부를 각각 확인했다. 확인 날짜를 썼다.
