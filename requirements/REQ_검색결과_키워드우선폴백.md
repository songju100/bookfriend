# 검색 결과 키워드 우선 폴백 추천

## 목적
검색 조건을 모두 만족하는 책이 없을 때도 검색어와 관심주제를 바탕으로 관련 도서를 최대 5권 제안한다.

## 상세 기능 정의
- 현재 검색 조건에 정확히 맞는 결과가 있으면 기존 결과 처리 방식을 유지한다.
- 정확한 결과가 0권이면 전체 도서 목록에서 검색 키워드와 관련된 책을 먼저 모은다.
- 키워드 후보 안에서는 선택한 관심주제·진로계열·테마와 일치하는 책을 우선 정렬한다.
- 최대 5권이 되도록 남는 자리는 관심주제에 맞는 책으로 채우고 중복 도서는 제외한다.
- 사용자가 키워드를 입력하지 않았거나 키워드와 연결되는 책이 없으면 관심주제 후보를 사용한다. 관심주제도 지정되지 않았으면 기존 검색어 관련도를 기준으로 최대 5권을 고른다.
- 읽기 난이도와 읽고 싶은 이야기 조건은 폴백에서 후보를 모두 제거하는 필터 대신 보조 정렬 기준으로 반영한다.

## UI 변경점
- 폴백 결과 개수는 실제 표시되는 후보 수(최대 5권)를 안내한다.
- 폴백에서는 더 보기 버튼을 표시하지 않는다.
- 현재의 정확 일치 결과 카드와 검색 조건 UI는 유지한다.

## 예외 처리
- 모든 조건에서 관련 후보가 없으면 빈 결과 안내를 표시한다.
- 검색어·주제 후보가 겹쳐도 한 권은 한 번만 표시한다.
- 데이터 로딩 실패 시 기존 로컬 도서 목록에서 같은 규칙을 적용한다.

## 데이터 및 동기화 영향
- 데이터 구조, 외부 서비스, 브라우저 저장 방식은 변경하지 않는다.
- 검색 결과 후보의 로컬 정렬과 표시 개수만 변경한다.

## 완료 검증 기준
- 정확 일치가 있을 때 기존 결과가 유지된다.
- 정확 일치가 없을 때 키워드 관련 책이 관심주제만 일치하는 책보다 먼저 표시된다.
- 폴백 결과는 5권을 넘지 않고 더 보기로 추가 노출되지 않는다.
- 중복 추천이 없으며, 키워드나 관심주제가 비어 있어도 앱이 오류 없이 결과 상태를 보여준다.
