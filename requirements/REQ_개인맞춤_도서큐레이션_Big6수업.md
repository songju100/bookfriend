# REQ_개인맞춤_도서큐레이션_Big6수업.md

## 목적
고등학교 도서부 학생들이 서로에게 흥미와 상황에 맞는 책을 추천하고, 그 과정을 Big6 Skills 정보활용교육 6단계에 따라 수행하도록 돕는 반응형 사이트와 6차시 수업 자료를 만든다. 태블릿을 우선 지원하고 PC와 휴대전화에서도 사용할 수 있게 한다.

## 자료원 및 연결 방식
- 국립어린이청소년도서관 사서추천도서: https://nlcy.go.kr/NLCY/contents/C10600000000.do (청소년 대상 필터, 검색, 목록 엑셀 다운로드를 제공)
- 구리여자고등학교 도서관 소장도서 검색: https://read365.edunet.net/PureScreen/SchoolSearch?schoolName=%EA%B5%AC%EB%A6%AC%EC%97%AC%EC%9E%90%EA%B3%A0%EB%93%B1%ED%95%99%EA%B5%90&provCode=J10&neisCode=J100000497
- 구리여자고등학교 전자도서관: https://gurigirl-h.dkyobobook.co.kr/main.ink
- 책따세 분야별 추천도서: https://readread.or.kr/bbs/board.php?bo_table=B16 (고등학생 수준 필터, 분야별 목록, 도서 소개)
- 국가교육과정정보센터(NCIC): https://ncic.re.kr/inv/org/list.do?step1=_1&step2=_13&step3=_30&step4=_30 (우리나라 교육과정 > 2022 개정 시기 > 고등학교(2022.12) 선택 화면)
- 에듀넷: https://www.edunet.net/ (KERIS 교육 콘텐츠·교수학습 자료 검색)
- 구리여자고등학교 홈페이지: https://gurigirl-h.goegn.kr/gurigirl-h/main.do (도서관/전자도서관 진입 링크 확인용)

각 외부 자료원으로 이동하는 링크를 사이트에 제공한다. 실제 브라우저에서 이용할 수 있는 것과 사이트 간 자동 데이터 연동은 별도 문제다. 외부 서비스의 공식 공개 API/다운로드 형식/약관을 확인하지 않은 상태에서 자동 스크래핑을 만들지 않는다. 기본 공유 도서목록은 data/books.js에 둔다. 사이트 안에서 책을 직접 등록하거나 CSV를 가져올 수 있고, 이 입력은 현재 기기에만 저장된다. 전 기기에 공유하려는 도서는 data/books.js에 반영해 재배포한다. 자료원 조회 실패 또는 소장 확인 전에는 불확실성을 표시한다.

## 상세 기능 정의
1. 별칭 기반으로 추천 대상의 선호 분야, 관심 주제, 읽기 상황/목적, 선호 난이도, 읽을 수 있는 분량을 받는다. 상세 대출 이력과 민감정보는 초기 버전에서 수집하지 않는다.
2. 공개 추천자료 및 교사 제공 학교 목록에서 책을 탐색한다. 제목·저자·출처 링크·출처 검증 상태·소장/전자책 확인 상태를 표시한다.
3. 난이도는 ‘가볍게 읽기 / 보통 / 깊이 읽기’로 안내하되, 교사 판단 태그임을 밝힌다. 공식 자료에 수준 표기가 있으면 출처 수준도 병기한다.
4. 교보문고 책 소개를 참고할 때 짧은 자체 요약과 출처 링크를 표시하고 원문을 대량 복제하지 않는다.
5. 월별 계기교육 테마 예시를 12개월 큐레이션으로 제공한다.
6. 추천 근거를 작성해 추천 카드/포스터로 출력하거나 Padlet 등에 붙여넣을 텍스트로 제공한다.
7. Big6 단계별 워크시트 및 체크리스트와 6차시 지도안을 제공한다.
8. 교사는 CSV/스프레드시트 가져오기로 학교 소장목록을 더할 수 있다. 외부 사이트 자동 로그인, 개인 대출이력 수집, 비공개 데이터 접근은 하지 않는다.

## Big6 6차시
1. 과제 정의: 추천 대상과 상황 파악, 문제·요구 정의 및 추천 질문 작성.
2. 정보탐색전략 수립: 자료원 범위와 검색어, 평가 우선순위 선정.
3. 소재 파악 및 접근: 도서관 서가와 온라인 자료원에서 책·소장/전자책 여부 확인.
4. 정보 이용: 책·발췌·미리보기·신뢰할 수 있는 소개를 읽고 핵심 정보와 난이도 근거 추출.
5. 정보 종합: 요구와 책 특징을 연결해 추천 이유 작성, 카드·포스터 제작.
6. 정보 평가: 과정·결과를 평가하고 실제 도서관 안팎에 게시, 독자 반응과 성찰 기록.

## UI / 완료 기준
- 태블릿 우선 반응형, 큰 터치 영역, PC·휴대전화 호환.
- 추천 대상 입력 → 자료원·책 탐색 → 근거 작성 → 추천 출력의 핵심 흐름 작동.
- 난이도 및 월별 테마 탐색, 출처 이동, 확인 가능한 상태 표기.
- 교사 제공 목록 가져오기와 브라우저 내 임시 저장 지원.
- 6차시별 학습 목표·학생 활동·교사 지원·산출물·평가 기준을 제공.
- 개인 대출 이력/실명을 기본 수집하지 않는다.

## 구현 가정
초기 버전은 브라우저에서 동작하는 수업용 프로토타입으로 구현한다. 외부 자료원은 바로 열 수 있는 링크와 확인한 샘플 메타데이터를 제공하고, 학교 목록은 CSV로 가져온다. 자동 동기화/API 연동은 서비스별 기술·이용조건을 확인한 뒤 별도 작업으로 추가한다.
