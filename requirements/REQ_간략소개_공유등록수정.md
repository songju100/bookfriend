# 간략 소개 등록·수정 제안 연결

## 목적
학생이 책벗을 어느 PC·태블릿에서 열어도 책 소개글을 제출하거나 수정을 제안할 수 있게 한다.

## 상세 기능 정의
- 추천 검색 카드와 월별 테마 카드에 소개글 등록/수정 제안 링크를 표시하고 사용자가 제공한 Google Form을 새 탭으로 연다.
- 소개가 비어 있으면 `＋ 내용 등록하기`, 있으면 `소개글 수정 제안`으로 표시한다.
- 현재 Form은 서지사항과 100자 내외 소개글을 한 개의 장문형 필수 문항으로 받는다. 학생은 도서 제목·저자·출판사·출판년과 소개글을 입력한다.
- Form 응답은 연동된 Google Sheets에 저장된다. 학생 제안은 교사가 시트에서 검수한다.
- 이 단계에서는 책벗이 비공개 응답 시트를 직접 읽거나 제출 내용을 즉시 공개 소개에 반영하지 않는다. 승인한 내용을 사이트에 자동 반영하려면 공개 승인 데이터 또는 별도 Apps Script/API 연결이 추가로 필요하다.

## UI 변경점
- 추천 검색·월별 테마 카드에 `＋ 내용 등록하기` 또는 `소개글 수정 제안` 링크를 둔다.
- 링크는 새 탭으로 열어 학생이 책벗 검색 상태를 잃지 않게 한다.

## 예외 처리
- 학교 계정 로그인이나 권한이 필요할 수 있다. 접근이 거부되면 선생님에게 확인하도록 안내한다.
- 응답 전송 실패 시 기존 책 카드와 소개글은 변경하지 않는다.
- 학생에게 실명·개인 이메일을 입력하도록 유도하지 않는다.

## 데이터 및 동기화 영향
- 응답 저장과 교사 검수는 사용자의 Google Form/Sheet에서 처리한다.
- 웹사이트에는 비공개 스프레드시트 주소나 인증 정보를 넣지 않는다.
- 제출된 응답이 사이트 데이터에 자동 동기화되는 것은 범위 밖이다.

## 완료 검증 기준
- 두 카드 화면 모두 버튼이 지정된 Form을 새 탭으로 연다.
- 제목이 없는 소개와 기존 소개에 각각 등록/수정 제안 문구가 표시된다.
- 책벗의 원본 서지자료는 Form 응답만으로 덮어쓰이지 않는다.
