# 승인된 책 소개글을 책벗에 공유

## 목적
다른 PC·태블릿에서 학생이 소개글을 제출하고, 교사가 Google Sheets에서 승인한 내용만 책벗 추천 검색과 월별 테마에 공통으로 표시한다.

## 상세 기능 정의
- Google Form 응답 필드는 `책 제목`, `지은이`, `도서에 대한 소개글`로 분리되어 있다.
- 응답 시트에 교사용 `검수 상태` 열을 두고, 승인된 행만 `책벗_승인목록` 탭에 표시한다.
- `책벗_승인목록`은 책 제목·지은이·소개글만 포함하며, 응답 시간이나 비승인 제안은 내보내지 않는다.
- 이 승인 전용 탭을 CSV로 웹에 게시하고, 사이트는 게시 CSV 주소에서 데이터를 읽는다. 원본 응답 시트 전체를 게시하지 않는다.
- 사이트는 승인된 소개를 제목과 저자 기준으로 기존 도서에 연결해 기본 소개보다 우선 표시한다. 매칭되지 않는 도서의 응답은 별도 안내 대상으로 남기고 자동으로 엉뚱한 책에 연결하지 않는다.
- 새로고침하면 승인 시트의 최신 내용이 다른 기기에도 반영된다.

## UI 변경점
- 기존 카드의 내용 등록/수정 제안 링크는 유지한다.
- 승인 소개글이 있으면 추천 검색·월별 테마·추천 카드 미리보기에서 동일한 소개를 표시한다.

## 예외 처리
- 게시 CSV 연결이 실패하면 기존 책 소개와 제안 링크를 유지한다.
- 비어 있는 필수값이나 제목·저자 매칭이 모호한 행은 표시하지 않고 건너뛴다.
- 응답 시트 전체 URL이나 인증 정보는 사이트 코드에 넣지 않는다.

## 데이터 및 동기화 영향
- 승인 소개는 Google Sheets 게시 CSV에서 읽고, 브라우저 localStorage에만 저장하지 않는다.
- 게시되는 정보는 승인된 제목·저자·소개글로 제한한다. 개인정보·대기 제안은 공개하지 않는다.
- 학교 계정 정책상 특정 시트 게시가 금지된 경우, Google Workspace 관리자와 협의하거나 별도의 Apps Script 접근 제어 방식을 사용한다.

## 완료 검증 기준
- 서로 다른 기기에서 같은 승인 소개글이 추천 검색 및 월별 테마에 나타난다.
- `승인`되지 않은 행은 게시 탭 및 책벗에 나타나지 않는다.
- 매칭 불가·중복·빈 행이 다른 도서 소개글을 덮어쓰지 않는다.
- 폼 응답의 수정은 승인 CSV에만 반영되고, 공개 도서 원본 데이터는 변경되지 않는다.
