# 책 추천 검색 통합 요구사항

## 목적

책 추천 검색에서 옵션 하나만 골라도 결과가 나오도록 하고, 서로 다른 추천자료원과 우리 학교 소장목록을 하나의 결과 목록에서 찾게 한다.

## 상세 기능 정의

- 추천 주제 선택지를 `전체`, `문학`, `인문과학`, `사회과학`, `자연과학`, `테마`, `진로`로 바꾼다.
- `진로`를 누르면 다음 계열 체크박스를 펼친다: `인문계열`, `사회계열`, `교육계열`, `자연계열`, `공학계열`, `의약계열`, `예체능계열`. 한 개 이상 선택할 수 있다.
- 진로목록의 청구기호와 서명을 이용해 계열별 도서를 연결한다. 분류 규칙에 따라 연결할 수 없는 도서는 억지로 계열에 넣지 않는다.
- `테마`를 선택하면 작품 주제 태그 선택지를 보여준다. 월별 테마 페이지는 유지하되, 추천 검색 영역의 `연결하고 싶은 달` 입력은 삭제한다.
- 우리학교 소장목록, 기존 추천도서, 책따세, 국립중앙도서관, 경기도교육청 DLS 서평도서, 진로목록, 고등 교과연계목록을 하나의 검색 결과 목록에서 검색·필터링한다.
- 옵션이나 키워드로 정확히 일치하는 자료가 없으면 해당 옵션·주제에 가까운 후보를 최소 1권 보여주고 `비슷한 주제 추천`임을 표시한다. 정확 일치가 여러 권이면 기본 3~5권을 먼저 보여주고 더 보기로 확장한다.
- 결과 카드에 제목, 저자, 출판사·발행년, 짧은 소개 또는 소개 확인 링크, 추천 자료원, 학교 소장도서의 청구기호를 표시한다. 청구기호는 우리 학교 소장목록 자료에만 `소장 · 청구기호 …`로 표시한다.
- 진로목록은 제공된 `진로도서목록.xlsx`의 822권을 가져온다. 교과연계목록은 7개 시트의 고등학교 도서 210권을 가져오며 시트의 교과분야를 주제 태그로 보존한다.
- 경기도교육청 DLS 독서서평단 게시판에서 현재 공개된 월별 게시물과 연결된 도서 목록을 수집해 반영한다. 저작권을 고려해 서평 전문은 복제하지 않고 서지정보와 짧은 자체 요약 또는 원문 링크를 사용한다.
- 정적 GitHub Pages에서는 외부 사이트 자료를 브라우저가 실시간으로 안정적으로 읽는다고 가정하지 않는다. 공개 가능한 서지정보를 정적 JSON 자료로 정리해 사이트에 포함하고, 갱신 시 다시 생성한다.
- 학교 웹사이트에 게시되는 카탈로그는 공개 데이터임을 감안해 내부 등록번호, 대출상태, 반납예정일, 가격 등은 제외한다. 교과연계목록에서도 가격은 제외한다.

## UI 변경점

- 기존 관심주제 칩을 7개 상위 범주 선택 UI로 바꾸고, 진로 선택 시 7개 계열 체크박스를 표시한다.
- 검색어 입력과 옵션 선택 결과를 기존 추천도서 카드 영역에 함께 표시한다. 별도 학교 소장도서 검색창은 두지 않는다.
- 결과가 여러 자료원에서 겹치면 제목·저자 기준으로 중복을 줄이고, 자료원 배지를 함께 표시한다.
- 기존 `연결하고 싶은 달` 선택 UI는 제거한다. 별도의 월별 테마 메뉴·페이지는 유지한다.
- PC·태블릿·휴대전화에서 버튼과 체크박스를 누르기 쉽도록 반응형으로 배치한다.

## 예외 처리

- 제목·저자·소개가 엑셀에 없거나 비어 있는 값은 추정하지 않고 원자료 링크를 제공할 수 있는 항목만 표시한다.
- 공개 게시물의 첨부파일이나 서지정보를 읽을 수 없는 경우에는 해당 원문 링크를 자료원 카드로 제공하고 누락을 안내한다.
- 관심 주제와 계열이 여러 개 선택된 경우 어느 하나라도 일치하는 도서를 후보에 포함한다. 검색 결과가 0권이어도 빈 화면 대신 가장 가까운 후보를 안내한다.
- 소장목록은 엑셀 내보내기 시점의 자료이므로 실시간 대출 가능 여부로 표시하지 않는다.

## 완료 검증 기준

- 각 상위 주제와 각 진로 계열 옵션을 하나씩 선택했을 때 최소 1권이 표시된다.
- 검색어·주제·계열 조합으로도 검색 결과가 비어 있지 않고, 대체 후보는 관련성 안내가 표시된다.
- 연결하고 싶은 달 입력은 추천 검색 폼에서 사라지고 월별 테마 메뉴는 유지된다.
- 우리학교 소장도서는 다른 추천 자료와 같은 카드 목록에서 나오며 청구기호가 구분되어 표시된다.
- 진로목록 822권, 고등 교과연계 210권, 공개된 DLS 게시물 도서가 검색에 반영된다.
- 교과연계 가격 및 학교 카탈로그의 등록·대출 관리정보가 공개 JSON에 들어가지 않는다.

## 수정 대상

- `index.html`: 옵션 UI, 계열 체크박스, 필터·순위·폴백, 통합 카드 표시.
- `data/`: 진로·교과연계·DLS 서평도서 데이터 정리 및 기존 소장목록 연결.
- `.github/workflows/pages.yml`, `data/README.md`: 신규 검색자료 배포와 갱신 안내.

## 보완 요구사항: 등록 도서·전자책·서평 PDF (2026-11-17)

### 목적
추천 검색 화면을 단순화하고, 교사 직접 등록도서의 저장 위치를 분명히 하며, 학교 전자책과 2026년 DLS 월별 서평목록을 검색 결과에서 활용한다.

### 상세 기능 정의
- 제공된 2026년 1~10월 서평 PDF에서 책 제목, 저자, 출판사, 발행년, 월별 서평 주제, 대상 학년을 추출하여 `data/reviews.json`에 병합한다. 2월 자료는 초등 고학년임을 명시해 고등학교 대상 자료와 구별한다. 기존 기록과 제목·저자 기준으로 중복을 병합한다.
- 서평 전문은 게시하지 않는다. 검색카드에는 짧은 자체 소개/서평 주제와 원자료 확인 링크를 제공하며, 저자·출판사 등 PDF의 텍스트 추출이 불확실하면 추측하지 않고 빈 항목으로 둔다.
- `책 직접 등록하기`는 유지한다. 등록 자료는 기존 브라우저의 `bookbud-custom` 저장을 유지하고, 추천 페이지에 `내가 등록한 책` 목록을 노출한다. 등록 직후 목록을 갱신하고 새 책을 쉽게 찾게 한다. 이 저장은 기기·브라우저별 로컬 저장임을 안내한다.
- 추천 결과 중 학교 전자책 목록의 ISBN 또는 제목과 일치하는 책에 `우리학교 전자책 대출·열람` 링크를 제공한다. 링크는 학교 전자도서관으로 이동하고 최종 대출은 학생 로그인 후 해당 사이트에서 진행한다.
- 책벗 하단의 별도 `우리학교 소장도서` 검색 UI 및 연동 핸들러를 제거한다. 소장자료는 기존 추천 검색 및 결과 카드 내 청구기호 표시를 유지한다.
- `목록 CSV 가져오기`, `목록 JS 내려받기` 버튼과 불필요한 파일 입력·핸들러를 제거한다. 책 직접 등록 기능은 영향을 받지 않는다.

### UI 변경점
- 추천 결과 상단 또는 하단에 `내가 등록한 책 (n)` 영역을 추가하고 등록된 제목을 선택하면 해당 책 카드/추천 화면으로 이동한다.
- 전자책 일치 항목에 학교 전자도서관 링크 버튼과 로그인 후 대출 가능 안내를 표시한다.
- 자료원 검색창이나 CSV/JS 목록 관리 버튼은 화면에서 제거한다.
- PC·태블릿·휴대전화에서 영역이 읽히고 터치 가능하도록 반응형으로 유지한다.

### 예외 처리
- 브라우저 저장소를 사용할 수 없거나 JSON 손상 시 등록 실패를 알리고 기존 데이터는 덮어쓰지 않는다.
- 전자책 ISBN·제목 매칭이 불확실하면 대출 가능으로 단정하지 않고 전자도서관 검색 링크만 제공한다.
- PDF 텍스트가 스캔 이미지 등으로 추출되지 않으면 해당 도서 서지정보를 추측하지 않고 누락 항목으로 별도 안내한다.
- 2월 초등 고학년 목록은 자료 대상 학년을 명확히 표시한다.

### 완료 검증 기준
- 별도 소장도서 검색창, CSV 가져오기, JS 내려받기 버튼과 관련 핸들러가 제거되고 직접 등록은 유지된다.
- 기존 브라우저에서 저장된 두 권 및 새 등록 도서가 `내가 등록한 책`에 보이고, 해당 카드를 추천할 수 있다.
- 학교 전자책 일치 시 학교 전자도서관으로 연결되고 로그인 및 대출은 외부 서비스에서 완료된다.
- 1~10월 서평목록의 추출 가능한 도서가 검색에 포함되고, 2월 자료에 초등 고학년 표시가 보인다.
- 자바스크립트 구문, JSON 파싱, 검색/등록/전자책 링크를 확인한다.

### 예상 수정 파일
- `index.html`: 오래된 검색·목록관리 UI 제거, 직접 등록 도서 목록, 전자책 대출 링크.
- `data/reviews.json`: 2026년 1~10월 PDF 기반 자료 병합.
- `data/README.md`: 서평목록 갱신 범위 및 직접 등록 저장범위 안내.

### 승인 후 UI 세부 수정 (2026-11-17)
- 테마와 진로 체크 세부 항목은 해당 상위 분야를 선택했을 때만 펼친다. 기본 화면에서는 두 체크 영역 모두 숨긴다.
- 상위 분야 버튼 순서는 원래 요청대로 전체 → 문학 → 인문과학 → 사회과학 → 자연과학 → 테마 → 진로를 보장한다.


### 승인 후 월별 테마 탐색 보완
- 월별 테마 버튼을 누르면 추천 검색 화면으로 이동하지 않고 월별 테마 화면 아래에 주제 설명과 관련 도서 결과를 펼친다.
- 각 월별 핵심어·유의어를 도서 제목, 소개, 주제 태그, DLS 월별 주제와 대조한다. 관련 점수가 없는 책은 월별 결과에 넣지 않는다.
- 기본 5권을 표시하며 학교 소장 청구기호, DLS 대상 학년/월, 학교 전자책 링크 등 기존 메타정보를 재사용한다.
