# 국립어린이청소년도서관 목록 연계와 소개글 난이도 추정

## 목적
에듀넷에 소개된 국립어린이청소년도서관 중·고등/청소년 사서추천도서를 책벗 검색에서 찾고, 학교 소장도서와 겹쳐도 추천 출처를 올바르게 표시한다. 사용 가능한 소개글을 바탕으로 읽기 난이도를 참고용으로 자동 추정한다.

## 상세 기능 정의
- 첨부된 사서추천도서 엑셀에서 `청소년` 및 `중·고등` 대상 자료 568권을 가져온다. 입력 파일에는 제목·저자·발행처·연도·주제구분·추천대상 등이 있으나 도서 소개글 열은 없다.
- 새 정적 카탈로그 `data/nlcy.json`에 공개 추천자료의 서지·주제 정보만 보관하고, 목록 출처와 도착 URL을 `https://www.edunet.net/rcmmdBk/view/185/2514`로 지정한다.
- 해당 도서가 학교 소장목록에도 있으면 한 카드로 합치고, 카드의 대표 출처는 `국립어린이청소년도서관 도서목록`으로 표시한다. 실물 소장일 때는 확인된 청구기호를 계속 보여준다.
- 기본 소개글 또는 교사 승인 CSV의 소개글이 있는 책에 한해, 브라우저 로컬 규칙으로 `가볍게 읽기 / 보통 / 깊이 읽기` 중 하나를 추정한다. 기존에 확인된 `level`이 있으면 이를 우선하며, 추정 표시는 `소개글 기반 추정`이라고 분명히 구분한다.
- 소개글이 없으면 난이도를 지어내지 않는다. 추천대상(예: 청소년)을 별도 표시하고, 기존 교보문고 제목 검색 링크로 확인할 수 있게 한다. 엑셀 자체에는 교보문고 소개문이 없으므로 이 데이터만으로 교보문고 문구를 자동 수집하지 않는다.
- 추천 검색과 월별 테마에 동일한 NLCY 출처 및 책 정보를 적용한다.

## UI 변경점
- NLCY 추천자료 카드의 출처 문구를 `국립어린이청소년도서관 도서목록`으로 통일하고 자료원 링크는 에듀넷 목록으로 연결한다.
- 자동 난이도는 `소개글 기반 추정 · 보통`처럼 보여주고, 도움말/툴팁에 소개 요약으로 추정한 참고치임을 안내한다.
- 소개글이 없는 도서는 추천대상을 표시하고, 난이도 대신 교보문고에서 책 소개를 확인하는 동작을 제공한다.

## 예외 처리
- 공백·중복 행은 제외하고, 제목·저자는 정규화해 학교 소장목록과 병합한다. 제목·저자 식별이 모호하면 자동 병합하지 않는다.
- NLCY 자료의 소개글이 없는 경우 추정 난이도를 표시하지 않는다.
- 기존 소개글·승인 소개 CSV·소장 청구기호가 없는 도서도 카드가 깨지지 않도록 기본 안내를 표시한다.
- NLCY JSON 로드 실패 시 기존 추천·소장 검색은 계속 동작한다.

## 데이터 및 동기화 영향
- 변경 파일: `index.html`, `data/nlcy.json`, `data/README.md`, `.github/workflows/pages.yml`.
- 저장소에 공개되는 필드는 제목·저자·발행처·연도·추천대상·추천시기·주제·추천 출처이며, 추천사서 개인 이름은 앱 데이터에 포함하지 않는다.
- 외부 런타임 API, API 키, 서버, 사용자 저장소는 추가하지 않는다. 소개글 규칙 기반 추정과 정적 JSON만 사용한다.

## 완료 검증 기준
- 568개 청소년/중·고등 추천자료가 검색 가능하고 NLCY 목록 출처가 에듀넷 링크로 연결된다.
- 확인된 학교 소장도서는 NLCY 출처와 청구기호를 한 카드에서 함께 보여주며 중복 추천하지 않는다.
- 난이도 필드가 있는 책은 그 값을 유지하고, 없는 책은 소개글이 있을 때만 자동 추정 표식과 함께 결과를 표시한다.
- 소개글이 없으면 난이도 추정이 없고, NLCY의 추천대상과 교보문고 확인 링크가 유지된다.
